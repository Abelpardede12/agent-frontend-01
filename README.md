A fast, lightweight frontend for make.fun: the live bounty board with each bounty's reward, live pot, entry fee and time left; a bounty's page with its rules and rewards; its leaderboard; and an account's public profile — all reading make.fun's public API, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the board, a bounty's page, its leaderboard and a profile, each on its own hash route.
